
# Rice Classification Project

## Dataset
Rice (Cammeo and Osmancik) dataset from the UCI Machine Learning Repository.

- 3,810 observations
- 7 numerical features
- Target variable: Class (Cammeo or Osmancik)

## Project Structure

- `data/` - Original dataset
- `R/` - R scripts for data analysis and modeling
- `figures/` - Generated visualizations
- `results/` - Statistical and machine learning results

## Analysis Workflow

1. `00_load_data.R` - Load and inspect the dataset
2. `01_data_wrangling.R` - Check data quality and perform preprocessing
3. `02_eda.R` - Exploratory data analysis and visualization
4. `03_statistical_analysis.R` - Statistical tests and regression analysis
5. `04_data_preparation.R` - Train/test splitting and model preprocessing
6. `05_machine_learning.R` - Model training, cross-validation, and tuning
7. `06_model_evaluation.R` - Evaluate and compare model performance

## Collaboration

Each team member contributes to assigned analysis tasks.
